# Ressources enseignement fluides énergétiques

Site **produit automatiquement**. Ne rien modifier ici :
toute modification est effacee a la prochaine publication.

La source vit dans le depot de cours, sur le poste de l'enseignant.
Elle est regeneree par `_commun/modeles/site.py`.

## AVERTISSEMENT — ce site n'est pas destine aux etudiants

Il rassemble des pages de **formation du professeur**. Elles
contiennent des demonstrations completes, des corriges, des baremes
et les reponses aux questions posees aux etudiants.

Il est publie pour l'usage de son auteur, sur plusieurs postes. Le
site des etudiants est un autre depot, et aucun lien ne relie les
deux.

## Donnees personnelles

Aucune. Le suivi de lecture vit dans le `localStorage` du navigateur
et n'en sort pas : pas de compte, pas de cookie, pas de requete vers
un serveur.
